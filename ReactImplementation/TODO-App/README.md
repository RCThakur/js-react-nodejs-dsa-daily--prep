# 📝 Todo List App (React)

A simple and interactive Todo List application built using **React**. This app allows users to add tasks dynamically and manage their daily activities efficiently.

---

## 🚀 Features

- Add new tasks
- Prevent empty task submission
- Dynamic rendering of todo list
- Clean and responsive UI
- Built with React Hooks (`useState`)

---

## 🛠️ Tech Stack

- **Frontend:** React
- **Styling:** CSS
- **State Management:** React `useState`
