# ⚛️ React useEffect Practice

This project demonstrates different real-world use cases of the `useEffect` hook in React.

## 🚀 Features

- 📌 Update document title dynamically
- 🌐 Fetch data from API
- ⏱ Timer using setInterval
- 📏 Window resize event listener
- 🧹 Cleanup functions

---

## 📚 What is useEffect?

`useEffect` is a React Hook used to handle side effects in functional components.

Examples of side effects:

- API calls
- DOM updates
- Event listeners
- Timers
