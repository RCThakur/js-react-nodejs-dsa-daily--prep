# ⚛️ React useRef Practice

This project demonstrates real-world use cases of the **useRef hook** in React.

---

## 🚀 Features

- 🎯 Access DOM elements directly
- 🔁 Persist values across renders without re-rendering
- ⏱ Store previous state values
- ⚡ Improve performance by avoiding unnecessary re-renders

---

## 📚 What is useRef?

useRef is a React Hook that allows you to store a mutable value that **persists across renders** but **does NOT trigger a re-render when updated**.It is mainly used for DOM access and storing values between renders.
