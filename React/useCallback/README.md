# ⚛️ React useCallback Practice

This project demonstrates real-world use cases of the **useCallback hook** in React.

---

## 🚀 Features

- 🔁 Memoize functions to prevent unnecessary re-creation
- ⚡ Optimize performance with stable function references
- 🧩 Prevent unnecessary child component re-renders
- 🔗 Use functions safely in dependency arrays

---

## 📚 What is useCallback?

useCallback is a React Hook used to **memoize a function**, so it is not recreated on every render.

It helps improve performance when passing functions to child components or using them in dependencies.
